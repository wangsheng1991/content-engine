# Qwen-Image-2.1 实测

三家图像模型、同一台机器、同一份公开题面，全部用原题面同 seed。首轮 7 题只过 4 题 —— 而只把题面改成长描述，两道失败题当场都过了。

## 先说结论

::: notes
先说结论：这个 4/7 不是能力上限，是我们喂题的姿势不对。官方的推荐管线是三件事叠在一起：提示词增强器、2048 分辨率、40 步。我们首轮用的是原始短题面、1024 分辨率、20 步，三样一样没占。把题面改写成增强器那种长描述之后，两道丢物体的失败题当场都过了 —— 同分辨率、同 seed、同机器，只动了题面这一个变量。
:::

- 差距主要不在模型，在**口径**。
- 官方管线 = 提示词增强器 + 2048² + 40 步。
- 首轮三项一样没占。
- 短请求不吃 ≠ 不会画。
- 别拿榜单总分估实际出图体验。

## 首轮成绩单

::: notes
三家拉到同一台机器、同一张卡、同一份题单上：题面一字未改，全部取自公开评测集 GenEval、DPG-Bench 和 LongText-Bench，同 seed。组合题那一栏，Qwen 七题只过四题，另外两家七题全过。
:::

- 题面一字未改，全部取自公开评测集。
- 同机同卡同 seed，只换模型。

| 模型 | 形态 | GenEval 组合题 |
| --- | --- | --- |
| Qwen-Image-2.1 | 7B DiT / Qwen3-VL / RGBA VAE | 4/7 |
| SenseNova-U1.5 | 8B+8B MoT，8 步 | 7/7 |
| FLUX.2-klein-KV | 9B 蒸馏 + INT4，4 步 | 7/7 |

## 翻车在哪三题

::: notes
Qwen 的三次翻车很具体。第一题，画两个钟，它只画一个钟。第二题，一只紫色酒杯加一个黑苹果，黑苹果整个丢掉。第三题，一张长椅，在 1024 下结构崩坏，到 2048 就正常 —— 这一题是配置问题，不是理解问题。还有一个值得记的失败形态：密集小字上它会凭空生成整段看起来像英文、但一个词都不对的假字。
:::

- `a photo of two clocks` → 只画一个钟。
- 紫色酒杯 + 黑苹果 → 黑苹果整个丢掉。
- `a photo of a bench` → 1024² 结构崩，2048² 正常。
- 密集小字会生成「像英文但一个词都不对」的假字。

## 它独占的两块地盘

::: notes
但它也有两块独占的地盘。中文长文本逐行命中 18/20，和 SenseNova 打平，而 FLUX 是 0/20，它的中文是整段乱码。另外原生透明 RGBA 只有它支持，要出透明背景的素材，这一条直接决定选它。
:::

- 中文长文本逐行命中 18/20，SenseNova 18/20，FLUX 0/20。
- 原生透明 RGBA：**只有它支持**。
- 要出透明背景的素材，这一条直接决定选它。

## 差距从哪来

::: notes
把差距拆开看，第一位的贡献是缺官方提示词增强器，用的是原始短题面，消融实验两题全修复。第二位是口径不同：官方那句小模强效靠的是自家榜单的复合总分，那是一张总分榜，没有 GenEval 和 DPG 的分项，和七题过四题不是一个量纲，换算不过来。再往下是对手不同、抽样与打分口径，以及分辨率和步数。
:::

| 差距来源 | 贡献 |
| --- | --- |
| 缺官方提示词增强器，用的是原始短题面 | 最大 |
| 口径不同：官方复合总分 vs 单点通过率 | 大 |
| 对手不同：INT4 蒸馏 4 步 vs 榜上满血 FLUX | 中 |
| 每题 1 张、单 seed、组合题靠人眼判读 | 中 |
| 分辨率 / 步数 | 结构性失败大、文字类小 |

## 只改题面，其余全不动

::: notes
固定同一台机器、同一张卡，2048、20 步、seed 42，唯一的变化是把 GenEval 的原题面改写成增强器风格的长描述。两个钟那题，原题面照旧只画一个钟，长描述正好两个；紫色酒杯和黑苹果那题，原题面丢苹果，长描述两个都在、颜色绑定也对。这里必须说明一句：右边的长描述是人工模仿增强器风格写的，不是官方增强器的真实输出，我们没有部署它。所以这组对照证明的是题面形态影响巨大，不是官方增强器一定能把分拉回来。
:::

- 固定 2048²、20 步、seed 42，**只改题面**。
- 两个钟：原题面一个钟 → 长描述正好两个。
- 紫色酒杯 + 黑苹果：原题面丢苹果 → 长描述两个都在。
- 长描述是人工模仿的替身，不是官方增强器的输出。

## 2K 和 40 步不是万能药

::: notes
那是不是按官方配方堆上去就好了？把四道长文本题按 2048、40 步重跑：英文黑板菜单从 20.5% 掉到 13.7%，英文海报从 94.4% 掉到 80.6%，中文两题基本持平。平均字符准确率从 71.7 变成 68.5，没看到提升，代价却是每张 172 秒，而 1024、20 步是 52 秒。一个诚实的限定：2K 图的字号更小、字体更花，OCR 跨分辨率并不完全可比，所以只能说没看到提升，不能反过来说 2K 更差。
:::

| LongText-Bench 原题 | 1024²/20 步 | 2048²/40 步 |
| --- | --- | --- |
| 英文 · 黑板菜单 | 20.5% | 13.7% |
| 英文 · 音乐节海报 | 94.4% | 80.6% |
| 中文 · 幻灯片 | 81.5% | 81.1% |
| 中文 · 音乐节海报 | 90.2% | 98.6% |

- 平均字符准确率 71.7% → 68.5%，**没看到提升**。
- 代价：172 s/张 vs 52 s/张。
- 想要组合题过关，关键在提示词增强，不在分辨率。

## 换一套题：26 道垂直题

::: notes
公开榜单考的是通用能力，和这单活到底该用哪个模型对不上，所以另起了一套自建题面：9 个领域、26 道题、156 张出图。结论是九个领域没有一家通吃。SenseNova 拿下效果图、人像、UI 稿和漫画分镜，而且 1024 就能用；Qwen 拿下中文海报大标题和单独的游戏图标。还有一个反面的共同失败：要 12 个风格一致的线性图标，三家全崩。
:::

- 9 个领域、26 道自建题、156 张出图。
- 九个领域**没有一家通吃**。
- SenseNova：效果图、人像、UI 稿、漫画分镜。
- Qwen：中文海报大标题、单个游戏图标。
- 要「12 个风格一致的线性图标」→ 三家全崩。

## 怎么选

::: notes
一份结论：要出效果图、人像、UI 稿、漫画分镜，用 SenseNova，它 1024 就能用，比 Qwen 快五倍以上。要出番剧海报的大标题，或者要透明背景的 PNG，用 Qwen，这两项它独占。用 Qwen 出组合复杂的画面，先上提示词增强，别用极简句式硬问。要成套且严格一致的多元素，三家都别指望，老老实实后期对齐。最后一条：别拿榜单总分估算实际出图体验。
:::

- 效果图 / 人像 / UI 稿 / 漫画分镜 → **SenseNova**，1024² 就能用。
- 中文海报大标题、透明 PNG → **Qwen**。
- 组合复杂的画面 → 先上提示词增强。
- 成套且严格一致的多元素 → 三家都别指望。
- 别拿榜单总分估实际出图体验。
